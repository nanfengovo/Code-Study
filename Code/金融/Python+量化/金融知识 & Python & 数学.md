# 量化交易分类
## 交易产品
* 股票策略：用于投资股票的各种方法和技术，旨在实现收益最大化；常见的股票策略包括价值投资、成长投资、趋势投资、动量策略等。
* CTA策略：是一种利用期权合约进行对冲和套利的投资方式。它通过同时持有股票和其对应的看涨期权或看跌期权，投资者可以在市场波动时获得稳定收益。CTA策略主要在期货市场中应用，但也可用于股票市场。
* 期权策略：涉及使用期权合约，如买入call期权、卖出put期权等。期权策略可以用于投机、对冲风险或套利。通过灵活运用不同的期权组合，投资者可以控制和管理投资风险。
* FOF策略：是指将资金投资于其他基金，通常通过多个层级的基金组合来实现投资目标。通过选择适当的底层基金和投资策略，投资者可以分散风险、降低波动性和提高投资效率。
## 盈利模式
* 单边多空策略：追涨杀跌/追跌杀涨
	* - 追涨杀跌：这种策略的核心是买入价格较高的股票或资产，并在价格下跌时卖出，从而赚取价差。
    - 适用于看好某一市场趋势的投资者。例如，如果预期科技股将上涨，则买入并持有，当价格回落时卖出，获利。
	- 追跌杀涨：与之相反，这种策略是卖出价格较低的股票或资产，并在价格上涨时买入，等待其下跌以实现利润。
    - 适用于看淡某一市场趋势的投资者。例如，如果预期能源股即将上涨，则卖出后待其下跌获利。
* 套利策略 ：追求稳定无风险的投资 ；- 常见于外汇、期货和证劵市场：
    - 例如，在不同市场的同一种资产价格差异较大时，投资者可以在价格较低的市场买入，同时在价格较高的市场卖出，实现无风险或低风险的利润。
* 对冲策略：- 通过投资多种资产或金融工具来抵消潜在风险。
	- 分为阿尔法策略和事件驱动策略：
    - 阿尔法策略：利用预测模型识别市场中的异常收益，即“阿尔法收益”，以实现主动管理的投资。
    - 事件驱动策略：在特定市场事件（如经济数据发布、公司财报宣布等）发生时进行投资决策，对冲风险或捕获机会。
## 策略信号
* 多因子策略：- 通过综合考虑多个因素来评估资产的价值和风险。- 常见的因素包括宏观经济指标、行业趋势、公司基本面等。
* 均值回归策略：- 基于统计学中的均值回归理论，认为市场价格会趋向于市场平均水平。- 当价格偏离均值时，投资者预测其会回归到均值水平，从而在高点买入、低点卖出以获利。
* 动量效益策略：- 基于动量理论，认为市场趋势具有持续性。
				- 如果某一资产近期表现良好，投资者可能会预期其将继续上涨；反之亦然。
				- 适合短期交易者和市场情绪分析者。
* 二八轮动策略：- 强调关注少数优质资产（如前20%的公司或行业）而忽略大部分平庸的资产。- 认为优质资产可能持续表现良好，而普通资产则可能下跌。- 这种策略可能导致高收益但也可能带来高风险。
* 海龟策略：- 适合追求长期稳定收益的投资者。
* 机器学习策略：- 利用先进的机器学习算法进行投资决策。
				- 可用于预测市场走势、识别投资机会等。
			- 需要大量数据和复杂的模型，对普通投资者而言可能比较复杂。

# 量化交易策略分类
> 从交易产品、盈利模式、策略信号三个角度分类

## 交易产品
![[Pasted image 20260210085908.png]]
###  股票策略的盈利模式
股票：股份公司为筹集资金而发行给各个股东作为持股凭证并借以取得股息和红利的一种有价证券
期权：一种选择权，是一种能在未来某特定时间以特定价格买卖一定数量的某种特定商品的权利
期货：一种标准化合约，期货交易所统一制定的，约定在未来的某一确定的日期和地点按照约定的条件买卖一定数量和质量的标的资产的标准化合约
### 期权策略的盈利模式
盈利模式：期权合约差价（常用）；到期行权收益
>  期权的时间很长，会影响现金流

### CTA策略盈利模式
> 关注价格趋势获取利差

价格走势存在反身性，随着市场上涨或下跌的趋势得到加强，而认知上的偏移又会反映在市场上
### FOF策略
> 基金中的基金，是一种专门投资于其他投资基金的基金

通过资产配置来分散风险、平滑波动、改善组合收益风险比，从而优化投资者的持有体验尤其是在震荡的市场背景下，FOF产品的优势尤其明显
## 盈利模式分类
### 单边多空策略
> 低价买进，待股价出现单边下跌时卖出，赚取利差
### 套利策略
> 在金融市场利用某些金融产品价格与收益率暂时不一致的机会获取收益的策略
> 追求无风险套利，即价格变动所产生的无风险收益
### 对冲策略
> 对冲：指特意减少另一项投资风险的投资。同时进行两笔行情相关，方向相反、数量相当，盈亏相抵的交易

> 对冲策略： 在期货股票市场和股票市场同时进行等量反向交易，以锁定既得利润或成本，通过抵消两个市场的损益来规避股票市场的系统性风险
