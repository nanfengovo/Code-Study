## 关于虚拟DOM
1、本质是Object类型的对象（一般对象）
2、虚拟DOM比较轻，因为虚拟DOM在React内部使用，无需真实DOM上那么多的属性
3、虚拟DOM最终转换为DOM
4、内联样式，要用style = {{key:value}} 的形式写
5、虚拟DOM只有一个根标签
6、标签必须闭合
7、如果是小写字母开头，则将该标签转化为html中的同名元素，如果html中没有对于该标签中的同名元素则报错；如果是大写字母开头，react应该要去
