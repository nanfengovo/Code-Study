> 传统的RBAC是指基于角色的权限管理，具体来说就是新增权限 → 给角色分配权限 → 给用户分配角色
> 增强型的RBAC：新增权限→ 给角色分配权限 → 给用户分配角色（这里也可以直接给用户分配角色）
